Link your game account

Sign in or create a website account, generate a private verification code here, then enter the command yourself in game. We never ask for your Minecraft password.

Your typed profile name is not proof of ownership. This link verifies the UUID of the player who runs the command. Each game account can link to one website account.

Private account-link codes expire after 10 minutes. Public community reward codes are separate and do not require a website link or a donation.
Unlinking deletes the website association. It does not reset your game reward claims. Linked UUID and current player name are stored until you unlink.
