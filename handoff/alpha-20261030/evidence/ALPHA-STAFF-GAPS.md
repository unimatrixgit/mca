# Frozen alpha — staff workflow completeness audit

Audit only; no source, production data or services changed. Checked current source plus the exact Core1.0.27 release method list (SHA2561aba67f491fe470469465470b599055100f64eb5c6866cf375359663673fd327). These are earlier queue promises, not proposals for additions.

- **In-game Take + persistent case context is missing.** `ModerationGui.java:155–215` loads read-only cards and opens native osTicket links. `TicketCards.java:30–31` exposes only ticket id/number/subject/status/department/appeal/url, with no assignment, creator UUID or suspect UUID. `website/control-panel/game-tickets.mjs:12–17,53–61` is a bounded metadata query; no Take/context mutation API exists there. Assignment/replies in native osTicket do exist; do not call the whole ticket backend missing.
- **Ticket-directed target actions are missing.** No Creator/Suspect teleport selector, assigned-ticket/online-target gate, reusable case-target state or suspect inventory inspection/editor handler was found in game Java. `DuneEss.java:492–530` has existing staff teleport commands to Arrakis/sietch/spiceblow, optionally targeting an online player; these are not the requested case workflow. Core inventory serialization/storage and own inventory views are implemented; they do not constitute staff access to another player's inventory.
- **Staff target-wallet correction GUI is missing.** `AdminGui.java:20–22,71–90` has no target economy editor or ticket-linked economy action. `DuneEss.java:492ff` retains an admin solari command. DuneBank's personal/faction/staff treasury transfers and ledger are implemented, but they operate on those bank accounts rather than a selected suspect's economy correction.
- **House/political staff management GUI is missing.** `AdminGui.java:22,78` exposes `politics status` only. `Politics.java:135ff` implements real elected-player voting/appointments/invasion actions; no staff editing screen is present. Event-driven political/house rank sync and current-term outfit checks ARE implemented and must remain protected; this audit does not suggest inventing elected-office override rights.

Existing native local/network ban workflows, current-authority bank flows, NPC management, bounded ticket metadata and modern shared presentation are real implementations. `DuneMenus/StaffConsole.java` routes to them; a central renderer cannot provide the missing backends above.

Historical `ACTIVE-UPDATE-QUEUE.txt:19–21` records the explicit staff/context promises. The source staff manual also marks inventory editor, economy GUI and political GUI pending (`staff-manual.mjs:14–19`), but its unrelated stale chat/travel labels were NOT counted as evidence of missing live features. Root should reconcile these four gaps before declaring the frozen queue fully complete.
