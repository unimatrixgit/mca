# Conquest and imperial succession proposal

The design connects funded invasions, strategic capture, quest objectives, imperial succession, legitimacy, council decisions and rebellion across five planetary servers and the website. It is ready for policy and architecture review; no implementation or production change is included.

- [Existing source integration](INTEGRATION.md) identifies current classes, SQL contracts and consumers, including the distinction between faction leadership and CP clans.
- [Complete design](DESIGN.md) covers the fifteen requested deliverables, with configurable defaults, state transitions, schema proposals, safeguards, a Kaitain example and implementation gates.

Task 371's announcement was published on 5 November 2026 as planned design work. Sunday 8 November remains an intended testing target conditional on an approved, implemented and verified scope. This proposal does not create another announcement or claim readiness.
