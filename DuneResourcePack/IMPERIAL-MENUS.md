# Imperial GUI artwork

The GUI set contains an emerald/sapphire trading chest, sealed job contract, imperial compass and confirmation seal. The transparent atlas was generated with ImageGen and revised to keep the symbols within their quadrants. Original images and the reproducible pack assembly recipe are retained under the project workspace's `output/imperial-gui-art/` directory.

Item model IDs: `dunerealms:gui_market`, `gui_contract`, `gui_compass`, `gui_confirm`. Each JSON model selects its quadrant through fixed face UV coordinates. No atlas cropping or replacement of existing currency, creature, planet or office artwork is required. All entries in the previously published pack remain byte-identical; nine entries are added.

Versioned download: https://www.dunerealms.com/downloads/DuneRealms-Imperial-GUI-1.21.4-v2.zip

SHA-1: `6c78f0f7379619b1ecd2bdac19be8e1ce8b78ab5`.

The server sends this optional Java resource pack on joining Arrakduin. Clients must accept/reload it to display custom artwork. Pack JSON, references, atlas alpha/quadrant separation and public download hashes are checked. Actual Java/Bedrock rendering remains a client acceptance check; this document does not claim a Minecraft screenshot was verified.
