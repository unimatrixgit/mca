# Vaerkring Reserve artwork deliverables

Created with the built-in imagegen tool. Original PNG masters are kept alongside this file; web production assets are optimized WebP, and game icons are transparent PNG at 64px and 128px. All characters use Minecraft-style cubic heads and pixel features. The original imperial seal is shared across the series.

Paths are relative to the repository root except the masters/prompts, which are alongside this README.

Published in the exchange gallery and currency manual chapter. Full-note images retain natural aspect ratio; GUI previews are limited to 64px. The zero note is commemorative artwork only and is excluded from resource-pack items, currency denominations and redemptions. Canon character editions remain unofficial fan artwork, not licensed merchandise.
